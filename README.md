## Bone Fracture Classification Using Tensorflow in Deep Learning

Bone Fracture Classification System

Built a deep learning model for bone fracture detection using VGG16 with transfer learning.

Applied feature extraction by freezing pretrained convolutional layers and training custom dense layers for classification.

Developed a web interface using Flask, HTML, and CSS for image upload and prediction.

Containerized the application using Docker and deployed on AWS for scalable inference.
